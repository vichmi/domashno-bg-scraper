# Domashno-bg-scraper

## What is Domashno.bg scraper
This is a scraper which downloads the image of the problem you've choose. It's more simple and you will have saved all images so that you can come back every time with or without subscription in the site. \
My idea of that scraper is that I can download every single image of my maths' book but it's impossible because the site has limit of the problems you open every day (60 problems limit).

## Installing
Clone the repo, open a terminal in the directory and type this:
```
pip install -r req.txt
```
After that create the directory `units`

## Usage
First of all you need an account in the [site](http://domashno.bg/) so that you can see at least the first problems of the units. 
To have all problems you need to buy a subscription in the [site](http://domashno.bg/) \
Start the program, sign in and you will have a selection of three subjects. There are many options and they are good described while using the program.\
After you choose everything and the program has ended a new folder will apear in `./units/` named as the book you have chose and in it there should be folder of the unit you have choose and in it there should be all images of the problems you have chosen.
